# FOODTRACK-DB
FoodTrack es un proyecto de base de datos que implementa el esquema relacional inicial de una plataforma para la gestión de foodtrucks en una ciudad. Se utiliza Microsoft SQL Server como motor, DBeaver como cliente y Git/GitHub para el control de versiones, simulando un entorno de desarrollo profesional.

Estructura del repositorio

El proyecto se organiza en distintos branches según su propósito:

scripts: creación del esquema y tablas (DDL).

cambios: scripts de edición de tablas y consultas.

data: archivos CSV con datos crudos y scripts de ingestión.

relaciones: diagrama de relaciones del modelo.
