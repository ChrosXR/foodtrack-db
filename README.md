# FOODTRACK-DB
FoodTrack es un proyecto de base de datos que implementa el esquema relacional inicial de una plataforma para la gestión de foodtrucks en una ciudad.

El proyecto utiliza Microsoft SQL Server como motor de base de datos, DBeaver como cliente y Git/GitHub para el control de versiones. El esquema contempla foodtrucks, productos, pedidos, ubicaciones y detalle de pedidos, simulando un entorno de desarrollo profesional.
